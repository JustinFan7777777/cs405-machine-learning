# CS405 — Machine Learning

Coursework for **CS405 Machine Learning**, covering classical ML algorithms from fundamentals to deep learning.

## Contents

| Lab | Topic | Description |
|---|---|---|
| 01 | Python & NumPy | Scientific computing fundamentals |
| 02 | Preliminary | Probability, statistics, linear algebra review |
| 03 | Naive Bayes | Probabilistic classification |
| 04 | Linear Regression | Gradient descent, closed-form solutions |
| 05 | Decision Trees & Random Forest | Tree-based ensemble methods |
| 06 | Linear Discriminant Analysis | Dimensionality reduction for classification |
| 07 | Neural Networks | Feed-forward networks, backpropagation |
| 08 | CNNs | Convolutional neural networks for image tasks |
| 10 | SVM | Support vector machines and kernel methods |
| 11 | K-Means Clustering | Unsupervised learning |
| 12 | GMM Clustering | Gaussian mixture models and EM algorithm |
| 13 | Markov Decision Processes | Sequential decision making |
| 14 | Q-Learning | Reinforcement learning |

## Quick Start

Each lab is a self-contained Jupyter notebook:

```bash
cd lab03_naive_bayes
jupyter lab
```

## Topics Covered

- Supervised learning (regression, classification, SVMs)
- Unsupervised learning (clustering, dimensionality reduction)
- Ensemble methods (random forests)
- Deep learning (MLPs, CNNs)
- Reinforcement learning (MDPs, Q-learning)
- Probabilistic models (Naive Bayes, GMMs)
